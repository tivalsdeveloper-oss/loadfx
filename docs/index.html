Installation & core concepts

python -m pip install loadfx
python -m pip install --upgrade loadfx
Explanation: The first command installs loadfx into the active Python environment. The second upgrades an existing installation. Using python -m pip helps ensure pip belongs to the Python interpreter you intend to use.

Basic imports

from loadfx import Loader, ProgressBar, TextFX, Menu
Explanation: Imports give your program access to the main terminal building blocks. Import only the components you need in small scripts; larger applications can organize them into modules.

1. Loaders & loading effects

Loaders provide animated feedback while work is running.

dotsspinnerlinearrowsbouncepulsecirclesquarebrailleclockwavebarsblocksgrowshrinkorbitarcsnakepingheartstarmatrixscanmoon

Context-managed loader

import time
from loadfx import Loader

with Loader("Working", effect="dots"):
    time.sleep(2)
Explanation: Loader creates an animated status indicator. "Working" is the message shown beside the animation and effect="dots" selects the animation. The with block handles the loader lifecycle automatically, making this pattern convenient for a single operation.

Manual lifecycle

loader = Loader("Starting", effect="wave")
loader.start()
run_application()
loader.stop()
Explanation: Manual control separates starting and stopping. Use it when your application has a longer workflow or when you need to decide exactly when terminal animation begins and ends.

Custom frames

loader = Loader(
    "Processing",
    frames=["[   ]", "[=  ]", "[== ]", "[===]"]
)
loader.start()
do_work()
loader.stop()
Explanation: Instead of selecting a named effect, you provide your own sequence of frames. loadfx cycles through the frames while the loader is active, allowing application-specific animations.

Animation interval

loader = Loader("Syncing", effect="dots", interval=0.08)
loader.start()
run_sync()
loader.stop()
Explanation: interval controls the delay between animation frames. Smaller values normally make an animation appear faster; larger values reduce update frequency.

2. ProgressBar

from loadfx import ProgressBar

bar = ProgressBar(100)
for i in range(101):
    process(i)
    bar.update(i)
Explanation: 100 represents the total amount of work. Each call to update(i) tells the progress bar how much work has completed. Replace process(i) with the real operation in your application.

ETA and speed

bar = ProgressBar(100, show_eta=True, show_speed=True)
for i in range(101):
    process(i)
    bar.update(i)
Explanation: show_eta=True requests an estimated remaining time, while show_speed=True displays processing speed when supported by the implementation. These indicators are useful for downloads, builds and batch processing.

Custom presentation

bar = ProgressBar(
    500,
    width=40,
    show_percent=True,
    show_eta=True,
    show_speed=True,
    fill="#",
    empty="-"
)
Explanation: The first argument is the total work. width controls the visual length. fill and empty customize the completed and remaining portions. The other options add status information.

3. TextFX

Colors

from loadfx import TextFX

print(TextFX.red("Error"))
print(TextFX.green("Success"))
print(TextFX.yellow("Warning"))
print(TextFX.blue("Info"))
print(TextFX.magenta("Debug"))
print(TextFX.cyan("System"))
print(TextFX.white("Text"))
print(TextFX.gray("Muted"))
Explanation: These helpers apply terminal color to strings. Semantic colors can make CLI output easier to scan: errors can be red, successful operations green and warnings yellow.

Formatting

print(TextFX.bold("Important"))
print(TextFX.dim("Secondary information"))
print(TextFX.underline("Documentation link"))
print(TextFX.blink("Attention"))
print(TextFX.reverse("Selected"))
Explanation: Formatting helpers change text presentation without requiring you to write raw ANSI escape sequences yourself.

RGB, rainbow and gradients

print(TextFX.rgb("LOADFX", 97, 218, 251))
print(TextFX.rainbow("Rainbow terminal text"))
print(TextFX.gradient("Gradient text"))
Explanation: rgb() accepts red, green and blue channel values. rainbow() applies multiple colors across text, while gradient() creates a progressive color transition when supported by the terminal.

Typewriter and layout effects

TextFX.typewrite("Booting loadfx...", speed=0.03)
print(TextFX.box("Application ready"))
print(TextFX.banner("LOADFX"))
print(TextFX.center("Centered message"))
Explanation: typewrite() reveals text progressively. box() and banner() are useful for headings and status screens. center() helps align output for terminal presentations.

Advanced effects

print(TextFX.shadow("LOADFX"))
print(TextFX.glitch("SYSTEM"))
print(TextFX.wave("Hello"))
print(TextFX.shake("WARNING"))
print(TextFX.scramble("Loading..."))
print(TextFX.ascii("LOADFX"))
Explanation: These effects are presentation-oriented. Use them for startup screens, demos, games and creative CLI interfaces rather than essential machine-readable output.

4. Animation

from loadfx import Animation

Animation.fade_in("Welcome")
Animation.slide("Hello")
Animation.typewriter("Starting...")
Animation.glitch("SYSTEM ONLINE")
Explanation: Animation helpers are intended for moving or progressively displaying terminal content. They can be combined with loaders and TextFX to create richer startup screens and CLI experiences.

5. Menus

Single list

from loadfx import Menu
choice = Menu(["Home", "Projects", "Settings", "Exit"]).show()
Explanation: A list is the simplest menu data structure. The labels are both what the user sees and what your program receives as the selected value.

Single dictionary

choice = Menu({
    "Create project": "create",
    "Open project": "open",
    "Exit": "exit"
}).show()
Explanation: A dictionary separates the display label from the application value. This is useful when you want friendly text in the terminal but stable command values in your code.

Multiple dictionaries

choice = Menu([
    {"Python": "python", "JavaScript": "javascript"},
    {"HTML": "html", "CSS": "css"}
]).show()
Explanation: This pattern lets you supply menu choices from multiple dictionaries in one data structure. It is useful when options originate from different categories or configuration sources.

Nested menu data

choice = Menu({
    "Programming": {
        "Python": "python",
        "JavaScript": "javascript"
    },
    "Exit": "exit"
}).show()
Explanation: Nested dictionaries represent hierarchical choices. This is useful for applications with categories, subcommands or settings groups.

Multi-select

from loadfx import MultiMenu
selected = MultiMenu([
    "Python", "HTML", "CSS", "JavaScript"
]).show()
Explanation: MultiMenu is intended for workflows where users need to choose several options, such as selecting technologies for a generated project.

6. Widgets

Table

from loadfx import Table

table = Table(["Name", "Language", "Status"], style="rounded")
table.add_row(["loadfx", "Python", "Active"])
table.show()
Explanation: Table organizes structured information into columns. The header defines the columns, add_row() supplies a record and show() renders it.

Panel

from loadfx import Panel
Panel("Terminal toolkit for Python", title="loadfx").show()
Explanation: A panel groups a message inside a visual container. It is useful for status messages, help text and highlighted information.

Tree

from loadfx import Tree

tree = Tree("Project")
tree.add("src/loadfx")
tree.add("tests")
tree.add("README.md")
tree.show()
Explanation: A tree displays hierarchical information such as project directories, categories or configuration structures.

Dashboard

from loadfx import Dashboard

dashboard = Dashboard()
dashboard.add("CPU", "24%")
dashboard.add("RAM", "1.8 GB")
dashboard.add("Status", "Running")
dashboard.show()
Explanation: A dashboard combines multiple metrics into one terminal view. It is a natural fit for monitoring and system-oriented CLI applications.

7. Themes

from loadfx import Theme
Theme.use("cyberpunk")
Explanation: Themes centralize visual choices so different loadfx components can share a consistent appearance. The application can switch themes without rewriting every widget.

Documented theme names: default, dark, light, cyberpunk, matrix, retro, ocean, fire, minimal.

Custom theme pattern

Theme.create(
    "mytheme",
    primary="cyan",
    secondary="blue",
    success="green",
    error="red"
)
Theme.use("mytheme")
Explanation: This pattern defines application-specific theme values and then activates the new theme. Exact supported theme parameters should be checked against the installed loadfx version.

8. Notifications

from loadfx import notify

notify.success("Project created")
notify.error("Connection failed")
notify.warning("Low disk space")
notify.info("Update available")
Explanation: Notifications provide consistent visual feedback for success, errors, warnings and informational events. They are useful when a full widget would be unnecessary.

9. Tasks

from loadfx import Tasks

tasks = Tasks()
tasks.add("Download")
tasks.add("Extract")
tasks.add("Install")
tasks.run()
Explanation: A task collection represents a multi-stage workflow. This pattern fits installers, project generators, deployment tools and setup programs.

10. Logging

from loadfx import Logger

log = Logger()
log.info("Starting application")
log.success("Database connected")
log.warning("Cache is almost full")
log.error("Connection failed")
Explanation: The logger gives application events consistent severity labels. Use informational messages for normal progress, warnings for recoverable concerns and errors for failures.

11. Terminal utilities

from loadfx import terminal

terminal.clear()
print(terminal.width())
print(terminal.height())
terminal.cursor.hide()
terminal.cursor.show()
terminal.title("My loadfx App")
Explanation: Terminal utilities manage presentation details such as clearing the screen, reading dimensions, controlling cursor visibility and setting the terminal title.

Capability detection

terminal.supports_color()
terminal.supports_unicode()
terminal.is_interactive()
Explanation: Capability checks allow an application to choose a compatible output mode. For example, a program can fall back to plain ASCII when Unicode is unavailable.

12. CLI commands

loadfx demo
loadfx effects
loadfx themes
loadfx version
loadfx doctor
Explanation: demo is intended to showcase functionality, effects lists loading effects, themes lists theme information, version reports package version information and doctor is intended for environment diagnostics.

13. Complete application recipe

import time
from loadfx import TextFX, Loader, Menu

print(TextFX.banner("MY APP"))

with Loader("Starting", effect="dots"):
    time.sleep(1)

choice = Menu({
    "Run": "run",
    "Settings": "settings",
    "Exit": "exit"
}).show()

print("Selected:", choice)
Explanation: This combines three core ideas: TextFX creates the application heading, Loader provides feedback during startup and Menu gives the user a structured choice. It is a compact foundation for a larger CLI application.
