loadfx

Build polished command-line applications with loading animations, progress displays, styled text, interactive menus and terminal widgets — with zero runtime dependencies.

GitHubPyPI
24+ effectsSpinners, waves, matrix, orbit, bars, custom frames and more.
Interactive UIMenus, multi-select, tables, panels, trees and dashboards.
Developer toolingThemes, notifications, logging, tasks, animations and CLI commands.

Installation

python -m pip install loadfx
Upgrade from v1: python -m pip install --upgrade loadfx

Loading effects

Use a built-in effect or pass your own sequence of frames.

from loadfx import Loader
import time

with Loader("Downloading", effect="matrix"):
    time.sleep(2)

Progress bars

from loadfx import ProgressBar

bar = ProgressBar(100, show_eta=True, show_speed=True)
for i in range(101):
    bar.update(i)

Configure width, fill/empty characters, labels, percentage, ETA and processing speed.

TextFX

from loadfx import TextFX

print(TextFX.rainbow("LOADFX"))
print(TextFX.bold("Important"))
print(TextFX.rgb("Custom RGB", 80, 180, 255))
TextFX.typewrite("Hello from loadfx", speed=0.03)
print(TextFX.box("Application ready"))

Includes terminal colors, bold/dim/underline/blink/reverse formatting, RGB, gradients, rainbow text, typing, banners, boxes and centering.

Menus

List

from loadfx import Menu
choice = Menu(["Home", "Projects", "Settings", "Exit"]).show()

Dictionary

choice = Menu({
    "Create project": "create",
    "Open project": "open",
    "Exit": "exit"
}).show()

Nested data and multi-select

from loadfx import MultiMenu
selected = MultiMenu([
    "Python", "HTML", "CSS", "JavaScript"
]).show()

Terminal widgets

from loadfx import Table, Panel, Tree

Table(
    ["Name", "Status"],
    [["loadfx", "Active"]],
    style="rounded"
).show()

Panel("Terminal toolkit", title="loadfx").show()

Tree("Project").add("src/loadfx").add("tests").show()

Themes & presentation

from loadfx import Theme, notify

Theme.use("cyberpunk")
notify.success("Build complete")
notify.warning("Low disk space")
notify.error("Connection failed")

Use built-in themes or extend the presentation layer for your own terminal applications.

Tasks & logging

from loadfx import Tasks, Logger

tasks = Tasks()
tasks.add("Download")
tasks.add("Extract")
tasks.add("Install")
tasks.run()

log = Logger()
log.info("Application started")
log.success("Build complete")
log.warning("Cache is almost full")
log.error("Connection failed")
