Build polished command-line applications with loading animations, progress displays, styled text, interactive menus and terminal widgets.

GitHubPyPI

Installation & core concepts

python -m pip install loadfx
python -m pip install --upgrade loadfx
Design goal: simple imports and useful terminal output without runtime dependencies.

Basic import

from loadfx import Loader, ProgressBar, TextFX, Menu

Context-managed loading

import time
from loadfx import Loader

Troubleshooting & compatibility

ProblemCheck
Colors look wrongCheck terminal ANSI/color support and try plain output.
Unicode symbols failUse ASCII-friendly effects or check terminal.supports_unicode().
Animation is undesirableDisable animation in your application or provide a reduced-effects mode.
CLI command missingReinstall the package and ensure Python's Scripts/bin directory is on PATH.
Import errorRun python -m pip show loadfx and verify the active Python environment.
