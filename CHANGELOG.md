# Changelog

## 2.2.0

### Added

- 12 built-in `ProgressBar` styles: `classic`, `blocks`, `dots`, `dotline`, `arrows`, `squares`, `circles`, `braille`, `pulse`, `bars`, `hash`, and `equals`.
- Foreground color support for progress bars using named colors or 256-color indexes.
- Background color support for progress bars using named colors or 256-color indexes.
- Custom progress fill and empty characters.
- Runtime progress customization with `set_style()`, `set_colors()`, and `set_message()`.
- Progress updates using absolute values, `step=`, `message=`, or `progress=`.
- New `examples/progress.py` covering styles, colors, custom characters, runtime changes, and incremental updates.
- PyPI metadata with repository, homepage, and issue tracker links.

### Documentation

- Expanded README progress-bar documentation with a style reference table and color examples.

## 2.1.0

- Terminal UI toolkit release with loading effects, menus, widgets, forms, themes, animations, logging, dashboard primitives, and progress reporting.
