loadfx

Python terminal loading effects, text effects, progress bars and flexible interactive menus.

Version 1.0.0 · Python 3.8+ · Zero runtime dependencies

Loading
dots, spinner, arrows, pulse, circle, square, braille and custom frames.
TextFX
colors, formatting, typing, rainbow, RGB, gradients, banners and boxes.
Menus
single lists, dictionaries, multiple dictionaries and nested menus.

Installation

python -m pip install loadfx

Quick Start

from loadfx import Loader, TextFX, Menu
import time

print(TextFX.rainbow("LOADFX"))
with Loader("Starting", effect="dots"):
    time.sleep(2)
choice = Menu({
    "Start": "start",
    "Settings": "settings",
    "Exit": "exit"
}).show()
print(TextFX.green(f"Selected: {choice}"))

Loading Effects

Loader("Loading...", effect="dots")
Loader("Working", effect="spinner")
Loader("Custom", effect=["◐", "◓", "◑", "◒"])

Progress Bar

from loadfx import ProgressBar
bar = ProgressBar(total=100, text="Installing")
for i in range(101):
    bar.update(i)

TextFX

print(TextFX.red("Error"))
print(TextFX.green("Success"))
print(TextFX.bold("Important"))
print(TextFX.rainbow("LOADFX"))
print(TextFX.gradient("Gradient"))
TextFX.typewrite("Typing effect", speed=0.04)
print(TextFX.box("Hello"))
print(TextFX.banner("LOADFX"))

Menus

List

Menu(["Home", "Projects", "Settings"]).show()

Dictionary

Menu({"Python":"python", "Web":"web", "AI":"ai"}).show()

Multiple dictionaries

Menu([{"Python":"python", "JavaScript":"js"}, {"AI":"ai", "Web":"web"}]).show()

Nested

Menu({
    "Programming": {"Python":"python", "JavaScript":"js"},
    "Projects": {"New":"new", "Open":"open"}
}).show()

API

Loader — animated terminal status indicators.

Spinner — Loader-compatible spinner class.

ProgressBar — terminal progress display.

TextFX — text styling and effects.

Menu — interactive list/dictionary/nested menus.
